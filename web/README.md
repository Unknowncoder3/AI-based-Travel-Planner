# Roamly — AI Travel Planner

An evolving travel-planning SaaS prototype focused on visual destination discovery, hidden gems, local experiences, practical itineraries, and a compact AI travel buddy.

## Phase 1 — Interface

- Premium, responsive travel discovery landing page
- Destination cards, category filters, save interactions
- Quick destination finder and trip planner form
- Preserves the existing FastAPI `POST http://localhost:8000/generate` integration
- Compact doodle-style floating chat assistant in the bottom corner (not a full-page chatbot)
- The chatbot currently uses demo replies; live LLM integration is planned for a later phase
- Route-preview and hidden-gem imagery are illustrative at this stage; no real routing provider is connected yet

## Run the web app locally

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000.

For itinerary generation, run the existing backend separately according to the root project's backend instructions. The current frontend calls `http://localhost:8000/generate`.

## Notes

The displayed destination ratings and sample budgets are concept content, not live verified quotes. The UI deliberately labels the planner integration state and does not imply that demo chatbot answers are generated by a live AI model.

## Roadmap

1. Phase 1: review and refine the web interface.
2. Phase 2: integrate reliable place data, mapping/routing, verified attractions and activity metadata.
3. Phase 3: connect the compact chat widget to a grounded AI travel copilot.
4. Phase 4: saved trips, accounts, collaboration, export/offline support, and SaaS billing/usage limits.
